## 🚀 كيفية التشغيل

### 1. **التشغيل السريع**
```bash
# تشغيل النظام مباشرة
python excellence_mobile_system_v6.py
```

### 2. **استخدام ملفات BAT (Windows)**
```bash
# تشغيل النظام
run_system.bat

# إنشاء نسخة احتياطية
backup_system.bat

# استعادة نسخة احتياطية
restore_backup.bat
```

### 3. **الوصول للنظام**
- افتح المتصفح على: `http://localhost:5000`
- سجل الدخول باستخدام البيانات الافتراضية
